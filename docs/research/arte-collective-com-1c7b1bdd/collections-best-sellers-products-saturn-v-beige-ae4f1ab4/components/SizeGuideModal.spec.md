# SizeGuideModal

Client component, small lightweight modal triggered by the "Size guide" link. Dark overlay,
centered white card, close (X) button, simple table/list of the 3 sizes
(12"x18" / 20"x30" / 24"x36") with matching cm equivalents. Not deeply reverse-engineered (live
site's exact modal content wasn't reachable during inspection due to an unrelated rogue
redirect script interrupting interaction) — built as a reasonable, consistent placeholder that
matches the site's visual language.
